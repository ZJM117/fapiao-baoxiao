# 发票报销工具

把要报销的票据（PDF / OFD / XML / 图片）丢进一个文件夹，程序负责：
**解析 → 建台账 → 查重 → 生成报销单（PDF + Excel）→ 合并打印**。带界面，在浏览器里用。

## 两种跑法（同一套代码，靠环境变量切换）

| | 本机（Windows） | NAS / 服务器 |
|---|---|---|
| 启动 | 双击 `启动发票报销工具.bat` | Docker 容器 |
| 访问 | 自动打开浏览器 | `http://NAS的IP:8766` |
| 登录 | 不需要（身份记作「本机」） | 用户名 + 密码，4 种角色 |
| 数据 | 程序目录里 | `data/` 卷（挂到宿主目录） |

## 部署到 NAS

- **不在 NAS 上构建**（推荐，容器几十秒起好）：见 **`GitHub与镜像部署说明.md`** ——
  代码 push 上来后 GitHub Actions 自动构建镜像推到 ghcr.io，NAS 只负责
  `docker compose pull && docker compose up -d`。
- **在 NAS 上自己构建**：见 **`Docker部署说明.md`**。

本机没装 Docker 也能先自检一遍首启行为：`python 测试\diag_deploy_first_run.py`。

## 主要能力

- **票据解析**：增值税电子发票、数电票、机票行程单、铁路电子客票（含票面红字——退票 / 改签）、
  打车行程单、登机牌、OFD / XML
- **出行人识别**：票面 → 手机号对照表 → 文件夹名，三层兜底，外加人工核对面板
- **发票与行程单配对**：同笔业务挨着输出，附件不重复计钱
- **三种报销单版式**：费用报销单 / 差旅费报销单 / 模板二
- **多用户**：管理员 / 财务审核员 / 业务人员 / 只读，权限卡口在后端，带审计日志
- **台账真身是 SQLite**（`发票台账.db`），Excel 只是给人看的导出快照 ——
  几个人同时入库、改台账不会互相覆盖

## 数据安全（重要）

**仓库里只有代码。** 真实台账（`发票台账.db`）、票据、缓存（含手机号姓名对照表）、
生成的报销单都在 `.gitignore` 里，不会跟着上来；构建镜像时 `.dockerignore` 还会再挡一层。

推送前建议扫一眼 `git status`，确认列表里没有上面这些东西。

## 自检脚本

```bat
python 测试\diag_deploy_first_run.py    :: 模拟容器首次启动（建库/迁移/建管理员/登录）
python 测试\diag_db.py                  :: 数据层：并发入库、乐观锁、软删除、审计
python 测试\diag_auth.py                :: 登录、角色卡口、越权拦截、会话失效
python 测试\diag_files_guard.py         :: 静态文件服务的暴露面
python 测试\diag_server_mode.py         :: 服务器模式（Docker 那套环境变量）
```

全部在 `%TEMP%` 副本里跑，无窗口，不碰真实数据。
